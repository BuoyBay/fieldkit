# FieldKit

Import FieldKit for FieldCodec, EditSession and CommitField. Import
fieldkit.FieldMasks for MaskEditor. Both modules are in the fieldkit package.

See [API](api.md) for lifecycle, canonical values, caret mapping and platform
capabilities. Native typing is preserved; punctuation rewriting is not installed
as an IME or undo transaction handler.
